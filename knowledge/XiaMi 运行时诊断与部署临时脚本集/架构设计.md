本模块是一组独立的 Python 一次性脚本（后缀 `_tmp.py`）与一份持久化审计输出 `audit_runtime_output.txt`，彼此无相互导入，按用途分为四类：
- 数据库诊断：`inspect_tmp.py`、`inspect_current_tmp.py`、`inspect_bad_transcript_tmp.py` 直接以只读模式连接 `~/.hermes/profiles/xiami/state.db`，枚举表结构、统计角色分布、定位空 tool_calls 消息。
- 响应历史检查：`inspect_response_tmp.py` 连接 `response_store.db`，打印 conversation_history 的 role/keys/tail。
- MCP 验证：`verify_mcp_context_tmp.py` 通过 `HERMES_HOME` + `.env` 加载后调用 `tools.mcp_tool` 发现并执行 `game_get_time`，校验返回结构。
- 部署清理：`deploy_context_tmp.py` 修改 `config.yaml` 注入 context_length/compression 覆盖层，清理过时的 fallback MEMORY.md，同步 SOUL.md，并用 `ContextCompressor` + `project_messages` 对 response_store 做投影。
依赖方向单向指向外部包：`agent.context_compressor.ContextCompressor`、`smartnpc_context_projection.project_messages`、`tools.mcp_tool`，不反向被业务代码引用。
